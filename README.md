# Maria AI - Autonomous Android AI Agent & Phone Controller ⚡

Maria is an advanced Android AI Agent powered by **Gemini 3.8 Flash** that controls your real smartphone hardware with voice commands, codes applications live in an embedded interactive sandbox, and automates daily tasks.

---

## 🚀 Key Features

1. **AI Voice & Agent Interface:**
   - Real-time Speech-to-Text and voice Text-to-Speech (TTS).
   - Holographic Animated AI Orb reflecting listening, thinking, and speaking states.
   - Screen & Multimodal Vision Perception (diagnose code screenshots and analyze photos).

2. **Real Phone Hardware & System Controls:**
   - **Flashlight Actuator:** Voice control to turn phone camera torch on/off.
   - **Stream Volume Control:** Interactive volume slider, mute, and maximum level shortcuts.
   - **Play Store Downloader:** Voice command (e.g., *"Download Instagram"*) opens Google Play Store directly.
   - **Device Telemetry:** Live battery level, charging health, temperature, RAM usage, and internal storage stats.

3. **In-Phone Code Studio & Live Web Sandbox:**
   - Full-stack HTML, CSS, and JavaScript editor running inside an embedded Android WebView sandbox.
   - Live pre-loaded templates: **Cyber Neon Pong Game**, **Developer Portfolio**, and **Neumorphic Calculator**.
   - **One-Click AI Bug Fixer:** Automatically scans syntax errors, DOM listeners, and viewport settings to fix bugs.

4. **Market & Financial Telemetry:**
   - Real-time tickers for Bitcoin, Ethereum, Solana, S&P 500, NASDAQ, NVIDIA, Apple, and Gold.
   - Instant AI market forecasts and sentiment analysis.

## 📦 Automatic APK Build via GitHub Actions

This repository includes an automated CI/CD pipeline in `.github/workflows/build-apk.yml`.

### How to get your APK from GitHub:
1. Push your code to your GitHub repository using the AI Studio GitHub sync button.
2. Go to your repository on GitHub and open the **Actions** tab.
3. The **Build Android APK** workflow will run automatically.
4. Once completed (green checkmark), click on the workflow run.
5. Scroll down to the **Artifacts** section and download **`Maria-AI-debug-apk`**.
6. Unzip the file to find your installable `app-debug.apk` and install it on your Android phone!
